TYPEGAME FINAL

Запуск:
1. Распакуйте архив.
2. Откройте папку TypeGame_Final в VS Code.
3. Правой кнопкой по index.html.
4. Open with Live Server.

В проекте:
- 5 языков интерфейса: English, Русский, Беларуская, 中文, العربية.
- Яркая обложка с героями и городом.
- Три сюжетные игры.
- Кнопки «Как играть».
- Три уровня сложности в каждой игре.
- Звуковые эффекты.
